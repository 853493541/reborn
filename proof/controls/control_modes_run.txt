## CLASSICAL (normal) — `op=classical`

```
movetest strafe mode=classical yaw0=2.38 yaw1=2.38 d=0.00 cam0=2.34 cam1=2.34
movetest back   mode=classical yaw0=2.38 yaw1=2.38 d=0.00 cam0=2.34 cam1=2.34
movetest turn   yaw0=2.38 yaw1=4.26 d=1.88 cam0=2.34 cam1=0.71 camd=-1.62
land drop=600u roll=1 clip=f1b02yd握拳小跳c.ani rc=0
```
clip switches: `F1b02yd挪步左.tani` (strafe window), `F1b02yd后退01.tani` (back window).

- Strafe/back input moves the character with the **facing kept** (d=0.00) and
  selects the authored **side-step / back-pedal** clips — the classical game
  truth (`OPERATION_MODES_PLAN.md` §1).
- Turn keys: character +1.88 rad; camera yaw 2.34 -> 0.71 — the
  `cameraYawBehind` reflection (behind(4.26) = 4.712-4.26 = 0.45) with the
  15 deg `CameraAdjustYawWhenMoveTurnDisableAngle` drag lag (~0.26), so the
  camera stays behind through the turn.
- Landing roll branch unchanged.

## JOYSTICK — `op=joystick`

```
movetest strafe mode=joystick yaw0=2.38 yaw1=0.81 d=-1.57 cam0=2.34 cam1=2.34
movetest back   mode=joystick yaw0=0.81 yaw1=-0.77 d=-1.57 cam0=2.34 cam1=2.34
movetest turn   yaw0=-0.77 yaw1=1.13 d=1.89 cam0=2.34 cam1=3.78 camd=1.45
land drop=600u roll=1 clip=f1b02yd握拳小跳c.ani rc=0
```

- Strafe/back input **turns the body to the travel heading** (d = -1.57 rad per
  1 s window at the pi rad/s turn rate) — the joystick game truth; no strafe /
  back-pedal clips are selected.
- Movement does not move the camera (mouse owns it in joystick mode).
- Turn keys behave as in classical (camera drag), independent of this run's
  mouse-driven camera.

## Correction 2026-10-01 — classical A/D turns (bytecode re-decode)

Re-decoded the real handlers from the packed bytecode (`tools/controls/lua51_probe.py`):
StrafeLeftStart = proto 0/76, StrafeRightStart = 0/78; forward/back/turn = 0/65-0/74.
STRAFE is the only mode-branched movement command: CLASSICAL -> SetControl +
TurnLeft/RightStart when Camera_IsInFreeView(); JOYSTICK -> ResponseWASDKey
(double-tap aware). The earlier summary in OPERATION_MODES_PLAN.md (classical
strafe keeps facing) described only the non-free-view branch — corrected.

Host mapping: RC_FREEVIEW=1 (default) = A/D turn in classical (observed game
behaviour); RC_FREEVIEW=0 = decoded side-step branch.

Runs (RC_DEMO_MOVE=1 RC_AUTORUN=15000, exit 0):

| run | strafe line | back line |
|---|---|---|
| classical, default (free view) | `movetest strafe mode=classical yaw0=2.38 yaw1=-0.76 d=-3.14 cam0=2.34 cam1=5.22` | `d=0.00` + 后退01 (back-pedal) |
| classical, RC_FREEVIEW=0 | `movetest strafe mode=classical yaw0=2.38 yaw1=2.38 d=0.00` (side-step; 挪步 clips) | `d=0.00` |
| joystick | `movetest strafe mode=joystick yaw0=2.38 yaw1=0.81 d=-1.57 cam0=2.34 cam1=2.34` | `d=-1.57` |

d=-3.14 = 1 s hold at the host turn rate pi rad/s; classical camera follows
(cam 2.34 -> 5.22, cameraYawBehind reflection + 15 deg drag). Landing roll
unchanged (`land drop=600u roll=1 ... rc=0`).
