## Why a host build exists at all

The reborn client is a host app that loads the MovieEditor engine DLLs to run
the sandbox. Writing/reading memory in the game client is forbidden (AGENTS 4/
8), and the game client needs an account; therefore runtime probing is only
possible in our own host - which is why the host build diff table exists.
