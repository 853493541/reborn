Real JX3 camera values (2026-09-23)
===================================

Sources
-------
1. Per-user settings (text) in
   C:\SeasunGame\Game\JX3\bin\zhcn_hd\userdata\<account>\<region>\<server>\<role>\custom.dat
   Keys are Lua-ish: {k="...",v=...}.
2. JX3RepresentX64.dll (MovieEditor\bin64) - camera controller code/constants.
3. JX3UIX64.dll - Lua3DEngine_Get3DEngineOptionCaps binding (engine camera caps).
4. docs/netcode/UNIT_SCALE_AND_CHARACTER_SIZE.md - 1 engine unit = 1 cm.

2. g_Scene_tCameraRuntime (saved camera per role)
-------------------------------------------------
  {fYaw=..., fPitch=-0.34999978542328, fCameraToObjectEyeScale=1}   (default/untouched)
Observed fPitch range: -0.17 .. -0.78 rad; fCameraToObjectEyeScale 1 (0.9 on some)
=> default camera pitch = -0.35 rad = -20.05 deg.

3. Engine camera caps (Lua3DEngine_Get3DEngineOptionCaps, JX3UIX64.dll 0x18000682e)
-----------------------------------------------------------------------------------
  fMinCameraDistance  (vtable +0x48)
  fMaxCameraDistance  (vtable +0x50)
  fMinCameraAngle     (vtable +0x58)
  fMaxCameraAngle     (vtable +0x60)
Values come from the engine caps object (per graphics option level); not in any
accessible config. Confirmed default fMaxCameraDistance = 2000.0:
  JX3RepresentX64.dll const blob 0x180d2af90 = 44fa0000, preceded by
  -1.56298 (0x180d2af88) and 1.0 (0x180d2af8c); nearby strings
  "pCameraController", "pSkillMoveCamera", "pSpriteCamera", "camera control".
Also: "AdjustEyeScale", "InitCameraEyeScaleEnable", "InitEyeScale"
(0x180d2ad20/0x180d2fcd0/0x180d2fcf0).

4. Wheel zoom (ZoomCharacterCamera_Step, JX3RepresentX64.dll 0x180b3ce40)
------------------------------------------------------------------------
  xmm7 = fMaxCameraDistance (arg); assert fMaxCameraDistance > 0.0f
  xmm1 = [this+0x78]                       ; current distance
  xmm0 = fMaxCameraDistance * 0.2f         ; const 0x180cb9e9c = 0.2
  xmm1 = xmm1 / xmm0 * 120.0f              ; const 0x180cd8ab4 = 120
  step = clamp(xmm1, 10.0f, 120.0f)        ; const 0x180cad554 = 10
  if (flag) step = -step                   ; xorps sign mask 0x180cad610
  => step = clamp(current / (0.2 * fMaxCameraDistance) * 120, 10, 120) units

6. Units
--------
  1 engine unit = 1 cm, 1 m = 100 u (adult male mesh 181.64 u = 1.816 m).
  fMaxCameraDistance = 2000 u = 20 m. The host's old UnitsPerMeter = 192 was
  wrong (would make the adult 0.95 m).
