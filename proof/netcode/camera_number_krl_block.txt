5. Zoom step function
---------------------
JX3RepresentX64.dll ZoomCharacterCamera_Step @ 0x180b3ce40
  xmm7 = fMaxCameraDistance (arg), assert fMaxCameraDistance > 0.0f
  xmm1 = [this+0x78]                 ; current distance
  xmm0 = fMaxCameraDistance * 0.2f   ; const @ 0x180cb9e9c
  xmm1 = xmm1 / xmm0 * 120.0f        ; const @ 0x180cd8ab4
  step = clamp(xmm1, 10.0f, 120.0f)  ; const @ 0x180cad554
  if (flag) step = -step             ; sign mask @ 0x180cad610
  => step = clamp(current / (0.2 * fMaxCameraDistance) * 120, 10, 120) units

Related constants:
  0x180cade98 = 1.5707964 (pi/2)  assert fabs(fExpectPitch) < D3DX_PI * 0.5f
  0x180ca1918 = 0.001             setter lower clamp
  0x180ca1280 = 1.0               setter upper clamp
