# skill v6 — buff durations (Count x Interval, 16 fps) (2026-10-09)
# Build: reborn_client_skillv6.exe  (client/RebornClient.cs, client/Targeting.cs)

## Client truth (read-only, JX3ClientX64.exe)
- `KScriptFuncList::LuaGetBuffTime` @0x1401c0730 reads a buff's fields [+0x3c]/[+0x40]
  and pushes (Count*Interval, Count, Interval) to Lua -> the buff's timer is
  Count x Interval. `KBuffList::AddBuff` @0x140309690 only copies the struct (no scaling).
- Buff.tab (settings/skill/Buff.tab): Count = col 13, Interval = col 14, Intensity = col 10.
- Frame base 16 fps (cast frames confirm it: nChannelFrame=64 -> 4 s,
  nPrepareFrames=24 -> 1.5 s). 0 -> no expiry.

## Change
- New `ability_picker/tools/build_buff_times.py` emits `ability_picker/data/buff_times_f1.tsv`
  = {buffId, level, functionType, count, interval, intensity} for every buff id the roster
  applies (apply_f1 addBuffs/delBuffs + mechanics CALL_BUFF ops): 123 buffs / 346 rows.
- Runtime copy: C:\SeasunGame\MovieEditor\bin64\ability_picker\buff_times_f1.tsv.
- Client loads it; a buff's expiry = now + Count*Interval*1000/16 ms (0 = permanent). Self and
  target buff lists now expire (`buff expired self <id>` / `buff expired <target> <id>`).
  RC_BUFFTIMES overrides the path. CC control stays functionType-driven (unchanged).
