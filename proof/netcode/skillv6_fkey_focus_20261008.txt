# form's KeyDown never fires -> F1/F2/F3 tagging silently did nothing. (The same reason an
# app-wide EscKeyFilter already exists.)
# Fix: added FKeyFilter (Application.AddMessageFilter), same pattern as EscKeyFilter; consumes
# WM_KEYDOWN for VK_F1/F2/F3 (ignoring auto-repeat) and calls the catalog-tag actions.
