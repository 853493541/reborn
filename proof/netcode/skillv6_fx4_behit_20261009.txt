# skill v6 — FX4 target be-hit animation (W2) (2026-10-09)
# Build: reborn_client_skillv6.exe  (client/RebornClient.cs, client/Targeting.cs)

## Change
The client now plays the target's authored be-hit animation when the ability's
skill_caster row has IsPlayBehitAnimation=1 (hit_fx_f1.tsv col isPlayBehit). The
path is the engine's own default rule: the "_bat01" sibling of the target's idle
anim in the same `动作` folder (KRLCharacter::BeHittedByPlayer uses the literal
"bat01.ani" for npc_source targets), e.g.
  wj_练功木桩001_st02.ani -> wj_练功木桩001_bat01.ani.
Played via KGModelCLR.AttachModel(tgt.Handle).PlayAnimation(path,0,speed,0) and
restored to idle after 800 ms. RC_BEHIT=0 disables it (test hook).

## Client truth (recovered, JX3RepresentX64.dll — read-only disasm)
- KRLCharacter::BeHittedByNpc @ 0x1804cfb50: kind from the target frame data
  (call 0x180003a6c) selects one of the skill-caster model's loaded be-hit anims:
  kind 1 -> [rsi+0xa4], kind 2 -> [rsi+0x94], kind 6 -> [rsi+0x8c]; else the
  sibling path 0x1804d8700 with template `data/source/npc_source/%s/动作/%s_%s`.
- KRLCharacter::BeHittedByPlayer @ 0x1804d0220: for an npc_source target model it
  calls 0x1804d8700 with the literal "bat01.ani" (string @0x180caf980) -> the
  default be-hit animation. 0x1804d8700 (sibling builder) uses the template
  `data/source/npc_source/%s/动作/%s_%s` (string @0x180cac990).
- `npc_animation.txt` (the per-NPC AniID table; filepath.ini NpcAnimationModel) is
  NOT shipped in the readable client paks (generated at runtime), so the exact
  per-NPC be-hit path is resolved by naming convention. The dummy's authored file
  `wj_练功木桩001_bat01.ani` exists in the pak (321 bytes, MIN2 + bone01) and is
  exactly the derived sibling of its idle anim.
