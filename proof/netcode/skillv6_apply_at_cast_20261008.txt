# Build: reborn_client_skillv6.exe
# Research finding: for skills with EXECUTE_SCRIPT(self), the engine runs the skill script's
#   Apply() at CAST -- it is the runtime effect function (not a passive-only hook). So the Apply
#   actions must run for ALL such abilities, not just the 39 script-only ones.
# Also fixed: SetNormalCoolDown(posi, id) -> the cooldown row is the 2nd arg (id), not posi.

## Changes
#  - build_mechanics.py: normalCd = 2nd arg of SetNormalCoolDown (65029->7101, 65116->197).
#  - build_passives.py: extract Apply() actions for EVERY roster ability with an Apply function
#    -> apply_f1.tsv (137 abilities; 61 child casts, 137 add-buffs, 3 heals, 8 summons, 1 doodad).
#  - client: loads apply_f1.tsv and runs the Apply actions at cast (in addition to the mechanic
#    ops); self-centered castModes (CasterSingle/CasterArea) may cast without a target.
