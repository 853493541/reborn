# skill v6 — AddBuff id arg-position fix (2026-10-08)
# Build: reborn_client_skillv6.exe (data-only change; client reads apply_f1.tsv)
# Bug: build_passives.py took the FIRST numeric arg of AddBuff(...) as the buff id, but the
#   common form is AddBuff(owner, level, buffID, stack, ...) -> the id is arg index 2. So
#   e.g. 65136 `npc.AddBuff(0, 99, 108, 1, 100)` yielded id 0 instead of 108.
# Fix: AddBuff -> arg index 2 (3rd) when numeric, else first numeric; DelBuff -> arg index 0.
# Effect: 65136 add=108 (was 0); other abilities' add-buffs re-derived.

## Verified: 65136 -> apply 65136 -> +buff=[108]  (was [0])
